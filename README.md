## English

A precision platformer by **Introvert Arcade**. You wake outside a hollow tree as a zombie whose name is missing from the garden's guest list. Spikes, plants, and traps stand between you and the next foothold. Drawings and conversations along the way piece together a life from childhood to old age.

Download the ZIP, extract it completely, and run `IWBTZ/IWBTZ.exe`. Keep the EXE and PCK together. No Godot installation is required.

Includes a tutorial, seven main stages, four boss fights, an epilogue, and *Come Home for Dinner*. Chinese and English subtitles and voice acting are included. Use Test for direct stage and boss-phase access, with F4 player invincibility available for portfolio review.

Move with A/D, jump with W/Space, shoot with K, interact or use abilities with E, retry with R, and pause with Esc. Enter advances the story.

The package uses the approved playtest 63 / source snapshot 64. Automated campaign and resource checks passed. Full manual clears of every stage and boss remain to be verified.
